🤝 Smart Donation Item Matching Platform
📌 Project Overview

The Smart Donation Item Matching Platform is a web-based application developed using Python and Streamlit. It helps connect donated items with organizations or recipients who need them.

The platform compares donation details such as item category, item name, quantity, and location with recipient requirements and generates suitable matches.

🎯 Problem Statement

Donated items often fail to reach the people or organizations who need them because of a lack of efficient matching and coordination. This project provides a simple digital platform to match available donations with current requirements based on item details and location.

🚀 Features
🎁 Add and manage donation details
📋 Add recipient or NGO requirements
🔍 Automatically identify suitable donation matches
📊 View donation and requirement statistics
📍 Compare donor and recipient locations
📦 Compare available and required quantities
🎯 Generate a matching score
🖥️ Simple and user-friendly Streamlit interface
